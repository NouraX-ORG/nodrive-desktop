# NoDrive branding sweep: hits kept on purpose in shared and Linux files (Linux lane).
# Format: path-glob<TAB>regex<TAB>class<TAB>reason   (regex "*" = any hit in those files)
# Classes: internal | server-required | not-shipped | dead-code (all "internal") | legal.
# Only true internal identifiers and legal text belong here; user-visible hits are fixed
# by tools/rebrand.py instead. Checked by tools/check-branding.py.
